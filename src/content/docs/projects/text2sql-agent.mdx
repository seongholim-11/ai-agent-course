## 한 줄 정의

"지난 분기 지역별 매출 상위 3개 카테고리와 전년 대비 성장률을 차트로 보여줘" 같은 질문을 받아 스키마를 탐색하고, 읽기 전용 SQL을 실행하고, 샌드박스에서 pandas·matplotlib으로 분석해 차트와 해석을 돌려주는 에이전트.

## 아키텍처

```
질문 ─▶ Agent
         ├─ list_tables / describe_table / sample_rows   (스키마 탐색, just-in-time)
         ├─ search_examples(question)                    (유사 질문-SQL 예시 검색, few-shot)
         ├─ run_sql(query)  ── 읽기 전용 계정, 타임아웃 10s, 행 제한, 허용 스키마만
         └─ run_python(code, data_ref) ── Docker 샌드박스(네트워크 없음, 자원 제한)
         ▼
      답변(해석) + 차트 이미지 + 사용한 SQL
```

## 요구사항

1. 공개 데이터셋(예: 공공데이터 상권·매출, 샘플 커머스 DB)을 Postgres에 적재, 테이블 8개 이상
2. 스키마 설명 문서(테이블·컬럼 의미, 값 예시, 조인 관계) 작성 및 도구로 제공
3. SQL 에러를 모델에 돌려 자기 수정, 결과가 비면 조건 완화 재시도 (4주차)
4. DB 수준 읽기 전용 + 쓰기 구문 차단 + 쿼리 비용 제한 (10주차)
5. 분석 코드는 Docker 샌드박스에서만 실행, 데이터는 파일로 마운트 (18주차)
6. 결과에 사용한 SQL과 가정을 항상 표시(검증 가능성)
7. 모호한 질문("매출"이 총매출인지 순매출인지)은 되묻기

## 평가

| 지표 | 방법 |
| --- | --- |
| 실행 정확도 | 질문 40개, 정답 SQL의 결과와 에이전트 SQL 결과를 비교(결과 집합 일치) |
| 난이도별 | 단일 테이블 / 조인 / 집계·윈도우 함수 / 모호한 질문 |
| 자기 수정률 | 첫 SQL 실패 후 최종 성공 비율 |
| 안전 | 쓰기 유도·다른 스키마 접근 시도 10개 차단율 |
| 비용·지연 | 질문당 |

참고: 공개 Text2SQL 벤치마크(Spider, BIRD)의 평가 방식(실행 정확도)을 따르면 설명하기 쉽습니다.
