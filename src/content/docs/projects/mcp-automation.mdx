## 한 줄 정의

가상의 사내 시스템(직원 디렉터리, 회의실 예약, 이슈 트래커, 사내 위키)을 **OAuth로 보호되는 원격 MCP 서버**로 만들고, Claude·Cursor 같은 Host와 직접 만든 에이전트가 이를 이용해 "다음 주 화요일 디자인팀과 1시간 회의 잡고, 관련 이슈 목록을 회의 안건으로 위키에 정리해줘" 같은 업무를 처리한다.

## 아키텍처

```
Host(Claude Desktop/Code, Cursor, 내 에이전트)
   │ MCP (Streamable HTTP + OAuth 2.1)
   ▼
MCP Gateway ── 정책 엔진(도구별 허용/승인/거부, 레이트 리밋, 감사 로그)
   ├─ directory-mcp   (읽기)
   ├─ calendar-mcp    (읽기 + 예약: 승인 필요)
   ├─ issues-mcp      (읽기 + 생성)
   └─ wiki-mcp        (읽기 + 문서 작성)
         │ 서버별 최소 권한 서비스 계정 (토큰 패스스루 없음)
         ▼
   가짜 사내 시스템 (Postgres + FastAPI)
```

## 요구사항

1. MCP 서버 4개(또는 기능을 묶은 2개): tools, resources, prompts 모두 사용 (9주차)
2. 사용자 작업 중심 도구 설계(API 1:1 노출 금지), 도구 수 서버당 6개 이하
3. 원격 서버 OAuth 2.1(PKCE), 토큰 audience 검증, 다운스트림은 별도 자격 증명
4. 쓰기 도구에 annotations, Host에서 확인 UI
5. 게이트웨이 정책 엔진과 감사 로그 (18주차)
6. 도구 정의 해시 고정(rug pull 감지)
7. 위키 문서 내용 속 간접 인젝션 시나리오에 대한 방어 (17주차)
8. Claude Desktop/Code 또는 Cursor에 실제 연결한 데모

## 평가

| 지표 | 방법 |
| --- | --- |
| 작업 성공률 | 업무 시나리오 20개, 결과를 DB 상태로 코드 채점 |
| 도구 선택 정확도 | 궤적 평가(필수/금지 도구) |
| 도구 설명 개선 효과 | 개선 전후 성공률 |
| 보안 | 인젝션·권한 우회 시나리오 15개 공격 성공률 |
| 지연 | 도구 호출 p95 |
