## 학습 목표

- 이력서를 "무엇을 썼다"가 아니라 "무엇을 만들어 얼마나 개선했다"로 쓴다
- 면접 질문 은행의 모든 질문에 2분 안에 구조화된 답을 한다
- 에이전트 시스템 디자인 면접을 45분 안에 진행한다
- 라이브 코딩으로 에이전트 루프와 도구를 30분 안에 구현한다

## 이력서

### 프로젝트 항목 쓰는 법

나쁜 예:

> LangGraph, MCP, Langfuse를 활용한 멀티 에이전트 리서치 시스템 개발

좋은 예:

> **Report Generation Agent** (Python, LangGraph, MCP, Langfuse, Docker) · GitHub 링크 · 데모 링크
> - Orchestrator–Worker 구조로 병렬 리서치를 구현해 보고서 생성 시간을 싱글 에이전트 대비 58% 단축
> - 단계별 모델 분리와 프롬프트 캐시 구조 개선(적중률 31% → 78%)으로 보고서당 비용 $0.91 → $0.38, 품질 유지(50문항 평가, judge-사람 일치율 0.86)
> - 체크포인트 기반 재개와 멱등 도구로 워커 강제 종료 20회 시험에서 완료율 100%, 중복 부수효과 0건
> - 평가 CI를 구축해 프롬프트·모델 변경 PR의 회귀를 자동 차단

**동사 + 무엇을 + 어떻게 + 수치 결과.** 기술 이름은 괄호 안에 모읍니다.

### 기술 스택 섹션

[기술 스택 체크리스트](../../interview/question-bank/#기술-스택-체크리스트) 기준으로 **직접 써서 결과를 낸 것만** 적습니다. 면접관은 적힌 모든 것을 물어볼 수 있습니다.

## 면접 유형별 준비

### 1. 개념·경험 질문

[면접 질문 은행](../../interview/question-bank/)과 각 주차의 면접 질문 전부. 연습 방법:

1. 답을 펼치기 전에 **소리 내어** 2분 안에 답한다(녹음 추천).
2. 모범 답안과 비교해 빠진 핵심을 메모한다.
3. 내 프로젝트 경험을 한 문장 이상 섞어 답하는 연습을 한다. "저는 실제로 ○○에서 이렇게 했고 수치가 이렇게 바뀌었습니다."

### 2. 시스템 디자인

[시스템 디자인 면접](../../interview/system-design/) 페이지의 프레임워크와 예제 4개로 연습합니다. 친구나 스터디원과 45분 모의 면접을 2회 이상 하세요.

### 3. 라이브 코딩

자주 나오는 형태:

- 도구 2~3개를 가진 에이전트 루프를 SDK로 구현 (4주차, 30분)
- 간단한 RAG: 문서 청킹 → 임베딩 → 코사인 유사도 검색 → 답변 (6주차, 40분)
- 주어진 에이전트의 버그 찾기(tool_result 누락, 무한 루프, 블로킹 호출)
- 평가 함수 작성: 주어진 출력들로 정확도와 신뢰구간 계산

연습: 아무것도 보지 않고 4주차 루프를 30분 안에 다시 짜보세요. 두 번 하면 손에 익습니다.

### 4. 과제 전형

일부 회사는 2~7일짜리 과제를 줍니다. 이 코스의 습관이 그대로 통합니다. **요구사항 확인 → 가장 단순한 동작 버전 → 평가 세트로 측정 → 개선 → README에 설계 결정과 한계**. 기능을 많이 넣는 것보다 측정과 설명이 점수를 가릅니다.

### 5. 컬처·협업

"비개발자의 요구사항을 AI 기능으로 옮긴 경험", "AI가 틀렸을 때 사용자에게 어떻게 알릴지", "AI 기능 출시 여부를 데이터로 판단한 경험"이 자주 나옵니다. 국내 공고에서도 비기술 직군과의 소통 능력과 실행 중심 사고를 요구하는 경우가 많습니다.

## 지원 전략

- 공고는 "AI Agent Engineer" 외에 "AI Engineer", "LLM Engineer", "Backend Engineer(AI)", "ML Engineer(LLM)", "AI 서비스 개발"로도 검색합니다.
- 공고의 주요 업무를 보고 대표 프로젝트 중 가장 가까운 것을 이력서 맨 위에 둡니다.
- 경력 요건이 있어도 핵심 업무와 겹치는 프로젝트가 있으면 지원하고, 자기소개에 "운영 수준의 평가·관측·보안까지 구현했다"를 명확히 씁니다.

## 실습 과제

- [ ] 이력서 프로젝트 항목 3개를 위 형식으로 작성
- [ ] 질문 은행 전 문항 녹음 연습 1회, 약한 질문 10개 2회
- [ ] 시스템 디자인 모의 면접 2회 (피드백 기록)
- [ ] 라이브 코딩: 에이전트 루프 30분, RAG 40분 각 1회
- [ ] 지원할 공고 10개 목록과 각 공고에 맞춘 이력서 버전

## 마무리

24주를 끝냈다면, 에이전트를 **만들고, 측정하고, 지키고, 운영하는** 경험을 모두 해본 것입니다. 이건 2026년 기준으로 많은 경력자도 아직 체계적으로 해보지 못한 일입니다. 수치와 실패 기록이 여러분의 가장 강한 무기입니다.
